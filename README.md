# Desafio Técnico - Implementação Figma

## Sobre

Este projeto é a implementação de uma interface fornecida por meio de um layout fornecido como desafio no Figma.

## Stack

- HTML5
- CSS3
- JavaScript Vanilla

## Estrutura

```
├── index.html
├── README.md
├── DIAGNOSTICO.md
│
├── assets/
│   ├── images/
│   ├── icons/
│   └── fonts/
│
├── css/
│   ├── reset.css
│   └── base.css
│
└── js/
    └── main.js
```

- `css/reset.css`: normalizações básicas entre navegadores.
- `css/base.css`: estilos globais mínimos.
- `js/main.js`: ponto de entrada do JavaScript.
- `assets/`: pastas reservadas para imagens, ícones e fontes que serão adicionadas durante a implementação.

## Como executar

Não há dependências ou build. Basta abrir o arquivo `index.html` diretamente no navegador, ou servir a pasta com um servidor estático simples, por exemplo:

```
npx serve .
```
